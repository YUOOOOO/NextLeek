# 选股菜单与策略显示页 — Design Spec

日期：2026-08-21  
状态：待用户确认（self-review 已过）
范围：NextLeek 顶栏新增「选股」，落地 `/stock-pick` 首版（策略显示可点通；其余 tab 占位）

## 背景与目标

用户要对标 `i.gushi.in` 一类选股产品，但对方站点暂不可稳定抓取。约定流程：

1. 先在 NextLeek 搭「选股」页并**用现有因子池走通交互**。
2. 再对照对方策略/因子，逐步替换映射与筛股逻辑。

本 spec 只覆盖第 1 步。

## 非目标（本版明确不做）

- 不抓取、不镜像 `i.gushi.in`。
- 不实现「共振选股 / 帮我选股 / 行情分析」业务逻辑（仅占位）。
- 不改 `strategy-api` 因子计算引擎，不新增真实竞价/盘前因子。
- 不把选股结果当成可交易信号；结果表 v1 为可演示的 mock 行。
- 不调整「轮动」「因子池」既有职责（因子池仍只读；手选因子仍在轮动研究筛选层）。

## 信息架构

### 顶栏

顺序固定：

1. 轮动 → `/rotation`
2. **选股** → `/stock-pick`（本版新增）
3. 因子池 → `/factors`

高亮规则与现页一致：`path.startsWith('/stock-pick')` 时「选股」为 active。

### 选股页 Tabs

页内顶部 4 个 tab（默认 **策略显示**）：

| Tab | 本版行为 |
|---|---|
| 策略显示 | 完整可点通（见下） |
| 共振选股 | 占位「开发中」 |
| 帮我选股 | 占位「开发中」 |
| 行情分析 | 占位「开发中」 |

## 策略显示（默认 Tab）

自上而下三块：

### 1. 策略按钮区

固定 8 个策略（文案以产品口述为准）：

1. 竞价多头策略
2. 盘前强势量化
3. 晨星量化
4. 竞价阿尔法
5. 早盘之星
6. T+1闪电
7. 金色2点半
8. 大市值

交互：

- 默认选中第 1 个。
- 单击切换；同时刷新「绑定因子」与下方结果表。
- 样式对齐现有深色壳：按钮/chip，选中态可用轮动页主色强调（如 `#69f0ae` 系）。

### 2. 当前策略绑定因子

位于策略按钮与结果表之间。

- 展示当前策略映射到的 **现有因子池** factor codes，用 `factor_catalog`（或本地 `FACTOR_LABEL` 兜底）显示中文 label。
- 只读 chip，本版**不**做因子池同款原理弹窗（避免范围膨胀；需要对齐时可后加）。
- 若某策略临时映射为空：明示「尚未绑定因子」。

### 3. 结果表

列（精简固定）：

| 列 | 字段含义 |
|---|---|
| 代码 | 证券代码 |
| 名称 | 证券简称 |
| 涨跌幅 | 百分比展示 |
| 现价 | 最新价 |

- 数据：v1 **mock 行**，每个策略自带 2～5 条互不雷同的示例行；切换策略即换数据集（证明「点策略 → 出表」链路）。
- 空结果时表格保留表头 + 空态文案（若某策略故意配空数组，走空态）。

## 因子走通方式（临时映射）

### 原则

- **流程优先、语义后对齐**：现有 `factor_catalog` 偏 ETF 轮动因子，与对方 A 股竞价类策略**不保证同义**。
- 每个策略维护一份临时 `factorCodes: string[]`，仅用于 UI 走通与后续对标清单。
- 映射表放在选股页可维护位置（优先页内 `STRATEGY_DEFS` 常量；若实现时发现轮动/因子池已有可复用结构再抽，但本版不强制抽公共包）。

### 数据来源

- `GET /api/strategy/universe` → `factor_catalog` / `active_factors`（与因子池页同一 BFF 路径）。
- 不新增 strategy-api job 类型。
- mock 结果不依赖行情真源；断连 universe 时：策略按钮与 mock 表仍可用，因子 chip 用本地 label 兜底或显示 code。

### 建议的初始映射（实现可微调，对标前可整表替换）

| 策略 | 临时因子（示例，取自现有池） |
|---|---|
| 竞价多头策略 | `MOM_20D`, `BREAKOUT_20D`, `PV_CORR_20D` |
| 盘前强势量化 | `PRICE_POSITION_20D`, `VOL_RATIO_20D`, `OBV_SLOPE_10D` |
| 晨星量化 | `SHARPE_RATIO_20D`, `CALMAR_RATIO_60D`, `MAX_DD_60D` |
| 竞价阿尔法 | `SLOPE_20D`, `UP_DOWN_VOL_RATIO_20D`, `VORTEX_14D` |
| 早盘之星 | `MOM_20D`, `PRICE_POSITION_20D`, `BREAKOUT_20D` |
| T+1闪电 | `MOM_20D`, `VOL_RATIO_20D`, `PV_CORR_20D` |
| 金色2点半 | `PRICE_POSITION_120D`, `SLOPE_20D`, `SHARPE_RATIO_20D` |
| 大市值 | `AMIHUD_ILLIQUIDITY`, `CORRELATION_TO_MARKET_20D`, `MAX_DD_60D` |

说明：上表**不是**对标结论，只是让 chip 区有真实因子池内容可展示。

## 文件改动面

| 文件 | 变更 |
|---|---|
| `frontend/src/App.vue` | 菜单插入「选股」；`isStockPick` 高亮 |
| `frontend/src/router.ts` | 注册 `/stock-pick` → 新页 |

不改：`strategy-api`、因子池页勾选语义、轮动研究流水线。

## 视觉与文案

- 复用 `App.vue` 顶栏与深色背景；选股页内容区宽度可与轮动页（约 `max-width: 1100px`）对齐。
- 页内不要再叠「选股」大标题长说明；顶栏已表达频道。
- 占位 tab 文案统一、短：「开发中」。

## 验收标准

1. 顶栏可见：轮动 | **选股** | 因子池；选股在轮动后。
2. 打开 `/stock-pick` 默认在「策略显示」。
3. 8 个策略可切换；选中态清晰。
4. 切换策略时，中间因子 chip 随映射更新（label 优先中文）。
5. 下方表列仅为：代码、名称、涨跌幅、现价；随策略切换 mock 行变化或空态合理。
6. 另 3 个 tab 可切换且为占位，无报错。
7. universe 接口失败时页面不白屏：策略按钮 + 表仍可用。
8. 控制台无 Vite 编译错误。

## 后续阶段（本 spec 外）

1. 用户提供对方策略说明/截图 → 对比 8 策略与真实因子是否一致。
2. 替换 `STRATEGY_DEFS` 映射；必要时扩展因子目录（A 股竞价类）。
3. mock 结果表 → 真筛股 API。
4. 填充其余 3 个 tab。

## 风险

- **名实不符**：用 ETF 因子冒充竞价策略因子，易误导；UI 可不强调「已对齐」，对标完成前避免写成生产信号。
- **范围蔓延**：原理弹窗、真行情、其余 tab 一律推迟。
