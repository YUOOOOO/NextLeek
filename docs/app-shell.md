# 顶栏

文件：`frontend/src/App.vue`

菜单右侧显示：

- **当前时间**：北京时间 `YYYY-MM-DD HH:mm:ss`，每秒刷新
- **时段**：工作日按北京时间判断
  - **集合竞价** 09:15–09:25（开盘集合）
  - **开市** 09:30–11:30、13:00–14:57（连续竞价）
  - **尾盘集合竞价** 14:57–15:00
  - 其余为 **休市**

右上角固定写出集合 / 尾盘时间；当前落在哪一段就高亮。周末、午休、15:00 后都是休市。法定节假日未接交易日历，只按周一到周五判断。
